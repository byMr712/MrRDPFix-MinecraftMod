## 2. Problem Statement: Why This Mod Exists
When playing Minecraft through Windows Remote Desktop (RDP):
- Windows Remote Desktop protocol cannot properly emulate raw relative mouse motion (`GLFW_RAW_MOUSE_MOTION` with `GLFW_CURSOR_DISABLED`).
- Minecraft relies on relative cursor deltas generated by locking and hiding the mouse cursor with GLFW.
- Under RDP, GLFW receives either clamped deltas, sudden extreme displacement coordinates, or stops receiving relative deltas entirely.
- This produces the classic symptoms documented in bugs **MC-107122** and **MC-126875**:
  - The camera spins wildly and uncontrollably with any slight mouse movement.
  - The cursor hits invisible monitor boundaries and camera panning freezes.

## 3. How the Mod Works: Core Architecture
MrRdpFix replaces raw relative mouse movement with absolute cursor position tracking, smooth recentering, and operating-system-level cursor clipping.

### 3.1 Cursor Management & Win32 Clipping (`RDPMouseCursor.java`)
- Minecraft normally sets `GLFW_CURSOR_DISABLED`, telling GLFW to capture raw mouse deltas.
- In RDP mode, `RDPMouseClient.applyMode()` switches the window cursor mode to `GLFW_CURSOR_HIDDEN` instead of `GLFW_CURSOR_DISABLED`.
- Raw mouse motion is explicitly disabled (`glfwSetInputMode(window, GLFW_RAW_MOUSE_MOTION, GLFW_FALSE)`).
- To prevent the cursor from leaving the Minecraft window and clicking background applications or losing focus over RDP, the mod dynamically resolves and calls the Win32 `ClipCursor` API (`user32.dll` via LWJGL JNI).
- When the cursor is locked in-game, `RDPMouseCursor.clipCursor(window)` clips the cursor strictly to the window rectangle coordinates `(windowX, windowY, windowX + width, windowY + height)`.
- When the cursor is unlocked (e.g. inventory/chat opened, Alt pressed, or game paused), `RDPMouseCursor.releaseClip()` frees the cursor clip by calling `ClipCursor(NULL)`.
- A JVM shutdown hook is installed to guarantee cursor release even in case of an abrupt game shutdown.

### 3.2 Delta Interception & Seamless Recentering (`MouseMixin.java`)
- In `MouseMixin.rdpmouse$onSetup`, the mod intercepts GLFW cursor position callbacks (`glfwSetCursorPosCallback`).
- When RDP mode is enabled and the cursor is locked:
  1. **Delta Calculation:** Computes `dx = x - lastX` and `dy = y - lastY`.
  2. **Jump Suppression:** If a delta jump exceeds 25% of window width/height, it is ignored as a teleport/recentering artifact.
  3. **Sensitivity Boost:** Injects `dx * sensitivityMultiplier` and `dy * sensitivityMultiplier` directly into Minecraft's `cursorDeltaX` and `cursorDeltaY`.
  4. **Boundary Margin Guard & Recentering:** When the cursor approaches the window edges (within 15% margin or 20 pixels), the cursor is immediately recentered back to the window center `(winW / 2.0, winH / 2.0)` using `glfwSetCursorPos`.
  5. **Recentering Flag (`justRecenter`):** Setting `justRecenter = true` ensures the next cursor position update (which lands near window center) updates `lastX` and `lastY` without producing false camera deltas.

### 3.3 Sensitivity Boost Slider (`RDPMouseConfig.java`, `RDPMouseConfigScreen.java`)
- Because absolute mouse tracking over RDP can feel heavier than raw input, a configurable sensitivity boost is provided.
- Configurable from 0% to 100% boost (default: 75%).
- Multiplier formula: `RDPMouseState.sensitivityMultiplier = 1.0 + (percent / 100.0)`.
- Stored persistently in `.minecraft/config/rdpmouse.json`.

### 3.4 Keyboard Camera Pan (`RDPMouseClient.java`)
- Dedicated key bindings for camera panning via keyboard:
  - Arrow Left: Pan Camera Left
  - Arrow Right: Pan Camera Right
  - Arrow Up: Pan Camera Up
  - Arrow Down: Pan Camera Down
- Dynamic speed acceleration based on held tick count: `Math.min(2.0 + ticks * 0.5, 25.0)`.
- Pan speed is normalized by vanilla mouse sensitivity factor (`Math.max(1e-4, d * d * d * 8.0)` where `d = sens * 0.6 + 0.2`) so keyboard rotation speed remains consistent regardless of the player's in-game sensitivity slider.

### 3.5 Free Mouse Key
- By default mapped to `Left Alt` (`key.rdpmouse.freemouse`).
- Holding Alt calls `mc.mouse.unlockCursor()`, allowing the user to reposition their physical cursor anywhere without moving the player's head. Releasing Alt restores cursor lock.

### 3.6 Mod Menu Integration (`RDPMouseModMenu.java`)
- Implements `ModMenuApi.getModConfigScreenFactory()`.
- Supplies `RDPMouseConfigScreen` directly to Mod Menu for in-game configuration.

## 4. Key Classes & File Structure
- `src/main/java/kesslercascade/rdpmouse/`
  - `RDPMouse.java`: Mod initializer and logger definition.
  - `RDPMouseClient.java`: Client lifecycle, keybinding registration, tick handler, camera pan calculation.
  - `RDPMouseCursor.java`: Win32 JNI ClipCursor / releaseClip binding.
  - `RDPMouseState.java`: Runtime state holders (`enabled`, `sensitivityMultiplier`, recentering markers).
  - `config/RDPMouseConfig.java`: JSON configuration loader and saver (`config/rdpmouse.json`).
  - `config/RDPMouseConfigScreen.java`: Vanilla-styled screen with RDP Mode cycling button and sensitivity slider.
  - `config/RDPMouseModMenu.java`: Mod Menu entrypoint implementation.
  - `mixin/MouseMixin.java`: Mixin targeting `net.minecraft.client.Mouse` for cursor callback replacement, lock/unlock hooks, and camera delta injection.
- `src/main/resources/`
  - `fabric.mod.json`: Fabric mod metadata (id: `rdpmouse`, name: `[MR] RDP Fix`).
  - `rdpmouse.mixins.json`: Mixin configuration file.
  - `rdpmouse.accesswidener`: Access widener for GLFW/Mouse fields.
  - `assets/rdpmouse/lang/`: Russian (`ru_ru.json`) and English (`en_us.json`) localizations.
